# סקיל: עדכן פרופיל

## מטרה
עדכן את הפרופיל האישי שלי (`.claude/profile.md`) בהתבסס על מה שלמדת עלי בשיחה הנוכחית או לפי מידע חדש שאני מספק.

## הוראות ביצוע

1. **קרא את הפרופיל הקיים** מ-`.claude/profile.md`
2. **שאל** מה ברצוני לעדכן, או אם לא צוין — הצע עדכונים בהתבסס על השיחה הנוכחית
3. **עדכן** את הקובץ עם:
   - המידע החדש
   - תאריך עדכון מעודכן
   - כללי עבודה מעודכנים אם נדרש
4. **הצג** את השינויים שבוצעו

## כללים
- **לעולם אל תמחק** מידע קיים — רק הוסף או עדכן
- שמור על פורמט עקבי עם הפרופיל הקיים
- אם מתגלה סתירה בין מידע ישן לחדש — שאל לפני שינוי
