# Field Report Bot — בוט דוחות שטח מוואטסאפ (ניר הנדסה)

אפליקציה נפרדת ועצמאית: כל המידע, ההערות והתמונות מהשטח נשלחים בוואטסאפ,
והבוט קולט אותם ישירות משם — בלי לפתוח אתר, בלי להעתיק־להדביק — ומייצר
לבד קובץ Word מוכן, בדיוק באותה תבנית ועיצוב של המסמכים הקיימים בדרייב
(אותם פונטים, גדלים, שוליים, כותרת עליונה/תחתונה עם הלוגו).

התבניות של 8 סוגי המסמכים (אלמנטים תלויים, סקר פערי בטיחות, תקרות תותב,
סקר תקופתי, סככות, חוות דעת הנדסית, מסמך כללי, אישור מבנים ארעיים) כבר
הותאמו בעבר במדויק למסמכי ה-Word המקוריים בדרייב — כולל שוליים (7 מ"מ
בצדדים, לוגו בכותרת/תחתית, פונט Arial) — והבוט משתמש באותה תבנית בדיוק.

לא נעשה שימוש ב-WhatsApp Business API הרשמי (שדורש אישור עסקי ותשלום) —
החיבור הוא לחשבון וואטסאפ רגיל דרך סריקת קוד QR, בדיוק כמו WhatsApp Web.

## התקנה חד־פעמית

1. התקן [Node.js](https://nodejs.org) (גרסה 18 ומעלה).
2. בתיקייה `field-report-bot`, הרץ:
   ```
   npm install
   cp .env.example .env
   ```
3. ערוך את `.env`:
   - `WHATSAPP_TARGET_CHAT` — שם מדויק של הצ'אט שהבוט יקשיב לו (מומלץ:
     קבוצת וואטסאפ ייעודית, למשל "דוחות שטח", עם עצמך כחבר יחיד).
   - `ANTHROPIC_API_KEY` — מפתח מ-console.anthropic.com ← API Keys ← Create Key.
   - `GENERATE_KEYWORD` / `RESET_KEYWORD` — המילים שמפעילות/מאפסות (ברירת
     מחדל: "צור דוח" / "דוח חדש").
4. הרץ `npm start`, וסרוק את קוד ה-QR שמופיע בטרמינל מהטלפון:
   WhatsApp ← הגדרות ← מכשירים מקושרים ← קישור מכשיר.
   אחרי הסריקה הראשונה הבוט זוכר את ההתחברות.

## שימוש בשטח

1. בצ'אט הייעודי, שלח בזמן הביקור טקסט חופשי (לקוח, כתובת, ממצאים) ותמונות
   — לפי הסדר, כמה שרוצים.
2. בסיום, שלח בצ'אט **"צור דוח"** — הבוט מנתח הכל עם AI, בונה את הדוח לפי
   התבנית המתאימה, ושולח בחזרה **בוואטסאפ עצמו** קובץ Word מוכן.
3. אפשר גם לציין את סוג המסמך במפורש: **"צור דוח: סככות"** (או "תקרות
   תותב", "פערי בטיחות" וכו') — כדי לא להסתמך על ניחוש אוטומטי.
   שלח **"עזרה"** לקבלת רשימת כל סוגי המסמכים.
4. שלח **"דוח חדש"** כדי לזרוק את מה שנאסף ולהתחיל אוסף חדש בלי ליצור דוח.

עותק של כל דוח שנוצר נשמר גם מקומית בתיקיית `data/`.

## הרצה קבועה ברקע

הבוט צריך לרוץ ברציפות כדי לקלוט הודעות. השאר את הטרמינל עם `npm start`
פתוח על מחשב שדולק תמיד, או הגדר עם [pm2](https://pm2.keymetrics.io/)
(`pm2 start src/index.js --name field-report-bot`) או במשימה מתוזמנת
שמריצה אותו אוטומטית בהפעלת המחשב — באותו אופן שבו `nir-dashboard-new/autostart`
מריץ את הדשבורד.

## חשוב לדעת

- הבוט מזהה נתונים (לקוח, כתובת, ממצאים) מתוך הטקסט באמצעות AI — כדאי
  לכתוב הערות בצורה ברורה (למשל: "לקוח: בית ספר ביאליק", "כתובת: הרצל 5").
  אפשר תמיד לפתוח את קובץ ה-Word שהתקבל ולתקן ידנית אם משהו זוהה לא נכון.
- אם התוכן שנשלח לא מכיל מספיק פרטים, שדות ריקים בדוח יישארו ריקים —
  הבוט לא ממציא נתונים.
- כדי לעדכן את התבניות עצמן (טקסטים קבועים, שוליים, לוגו) בעתיד — הם
  מוגדרים ב-`src/docGenerator.js`, זהה למבנה שב-`nir-reports/src/lib/docGenerator.js`.
