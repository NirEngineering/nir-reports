# Field Report Bot — בוט דוחות שטח מוואטסאפ (ניר הנדסה)

אפליקציה נפרדת ועצמאית: כל המידע, ההערות והתמונות מהשטח נשלחים בוואטסאפ,
והבוט קולט אותם ישירות משם — בלי לפתוח אתר, בלי להעתיק־להדביק — ומייצר
לבד קובץ Word מוכן, בדיוק באותה תבנית ועיצוב של המסמכים הקיימים בדרייב
(אותם פונטים, גדלים, שוליים, כותרת עליונה/תחתונה עם הלוגו).

התבניות של 8 סוגי המסמכים (אלמנטים תלויים, סקר פערי בטיחות, תקרות תותב,
סקר תקופתי, סככות, חוות דעת הנדסית, מסמך כללי, אישור מבנים ארעיים) הותאמו
במדויק למסמכי ה-Word האמיתיים והעדכניים ביותר בדרייב — כולל שוליים, גודל
הלוגו בכותרת/תחתית, וכיווניות RTL ברמת כל שורת טקסט (לא רק ברמת הפסקה) —
כדי שהמסמך שייווצר ייראה זהה, נקי ומקצועי בדיוק כמו המסמכים הקיימים.

לא נעשה שימוש ב-WhatsApp Business API הרשמי (שדורש אישור עסקי ותשלום) —
החיבור הוא לחשבון וואטסאפ רגיל דרך סריקת קוד QR, בדיוק כמו WhatsApp Web.

## שתי דרכי הרצה

- **מחשב מקומי** — הכי מהיר לבדיקה ראשונית, אבל הבוט עובד רק כשהמחשב דולק
  ומחובר לאינטרנט. מתאים לניסיון ראשוני, לא לשימוש קבוע.
- **שרת ענן (VPS) עם Docker** — רץ 24/7, ללא תלות במחשב שלך בכלל. זו
  הדרך המומלצת לשימוש אמיתי בשטח. ראה בהמשך "הרצה קבועה בענן".

## התקנה חד־פעמית (מחשב מקומי, לבדיקה)

1. התקן [Node.js](https://nodejs.org) (גרסה 18 ומעלה).
2. בתיקייה `field-report-bot`, הרץ:
   ```
   npm install
   cp .env.example .env
   ```
3. ערוך את `.env`:
   - `WHATSAPP_TARGET_CHAT` — שם מדויק של הצ'אט שהבוט יקשיב לו (מומלץ:
     קבוצת וואטסאפ ייעודית, למשל "דוחות שטח", עם עצמך כחבר יחיד).
   - `ANTHROPIC_API_KEY` — מפתח מ-console.anthropic.com ← API Keys ← Create Key.
   - `GENERATE_KEYWORD` / `RESET_KEYWORD` / `WIZARD_KEYWORD` — המילים
     שמפעילות/מאפסות/פותחות שאלון מודרך (ברירת מחדל: "צור דוח" / "דוח
     חדש" / "שאלון").
4. הרץ `npm start`, וסרוק את קוד ה-QR שמופיע בטרמינל מהטלפון:
   WhatsApp ← הגדרות ← מכשירים מקושרים ← קישור מכשיר.
   אחרי הסריקה הראשונה הבוט זוכר את ההתחברות.

## שימוש בשטח

יש שתי דרכים להזין מידע — אפשר לשלב ביניהן בחופשיות באותו ביקור:

**א. כתיבה חופשית** — בצ'אט הייעודי, שלח בזמן הביקור טקסט חופשי (לקוח,
כתובת, ממצאים) ותמונות, לפי הסדר, כמה שרוצים.

**ב. שאלון מודרך** — שלח **"שאלון: סככות"** (או כל סוג אחר) והבוט ישאל
שאלה אחת בכל פעם. לשאלות עם תשובות קבועות (למשל סטטוס: תקין/לא תקין)
הבוט שולח רשימה ממוספרת — **עונים עם מספר, או פשוט מקלידים תשובה חופשית
משלכם** במקום המספר. בסוף כל ממצא הבוט שואל אם להוסיף עוד אחד. שלח
**"בטל"** בכל שלב כדי לצאת מהשאלון (מה שכבר נענה נשאר שמור).

**לסיום, בשתי הדרכים:**

1. שלח **"צור דוח"** — הבוט מנתח הכל עם AI, בונה את הדוח לפי התבנית
   המתאימה, ושולח בחזרה **בוואטסאפ עצמו** קובץ Word מוכן.
2. אפשר גם לציין את סוג המסמך במפורש: **"צור דוח: סככות"** (או "תקרות
   תותב", "פערי בטיחות" וכו') — כדי לא להסתמך על ניחוש אוטומטי.
   שלח **"עזרה"** לקבלת רשימת כל סוגי המסמכים.
3. שלח **"דוח חדש"** כדי לזרוק את מה שנאסף ולהתחיל אוסף חדש בלי ליצור דוח.

> השאלון המודרך זמין רק לסוגי המסמכים מבוססי-הטבלה (אלמנטים תלויים, סקר
> פערי בטיחות, תקרות תותב, סקר תקופתי, סככות). לחוות דעת/מסמך כללי/אישור
> מבנה ארעי — כתיבה חופשית בלבד.

עותק של כל דוח שנוצר נשמר גם מקומית בתיקיית `data/`.

## הרצה קבועה בענן (מומלץ) — עובד גם כשהמחשב שלך כבוי

הבוט צריך לרוץ ברציפות כדי לקלוט הודעות. הדרך הנכונה לכך היא שרת קטן
וזול בענן שדולק תמיד (לא תלוי במחשב האישי שלך, ברשת הבית, בהפסקות חשמל
וכו'). בתיקייה כבר מוכנים `Dockerfile` ו-`docker-compose.yml` בדיוק
לצורך זה.

### שלב 1 — פתיחת שרת (VPS)

בחר ספק (למשל [Hetzner](https://www.hetzner.com/cloud/) or
[DigitalOcean](https://www.digitalocean.com/) — עלות טיפוסית 4-6$ לחודש),
צור שרת חדש (Droplet / Server) עם:
- מערכת הפעלה: **Ubuntu 24.04**
- התצורה הזולה ביותר (1 vCPU / 1-2GB RAM מספיק בהחלט)

הספק ייתן לך כתובת IP וסיסמת/מפתח SSH.

### שלב 2 — התחברות והתקנת Docker

מהמחשב שלך (חד־פעמי, אח"כ אין צורך לגעת במחשב שוב):
```
ssh root@<כתובת-ה-IP-של-השרת>
curl -fsSL https://get.docker.com | sh
```

### שלב 3 — העלאת הקוד לשרת

```
git clone https://github.com/NirEngineering/nir-reports.git
cd nir-reports
git checkout claude/whatsapp-reports-generator-yj8tje
cd field-report-bot
cp .env.example .env
nano .env   # מלא WHATSAPP_TARGET_CHAT ו-ANTHROPIC_API_KEY (Ctrl+O לשמירה, Ctrl+X ליציאה)
```

### שלב 4 — הרצה

```
docker compose up -d --build
docker compose logs -f
```

בלוגים יופיע קוד QR — סרוק אותו מהטלפון (WhatsApp ← הגדרות ← מכשירים
מקושרים ← קישור מכשיר). אחרי הסריקה אפשר לצאת מהלוגים (Ctrl+C) — הבוט
ממשיך לרוץ ברקע.

**זהו — מהרגע הזה הבוט פעיל 24/7, גם אם תכבה את המחשב שלך, גם אם השרת
עצמו יתאתחל** (Docker מוגדר להפעיל אותו אוטומטית מחדש בכל מקרה: קריסה,
אתחול שרת, וכו' — הודות ל-`restart: always`).

### עדכון הבוט בעתיד

אם יתעדכן קוד ב-branch (למשל תיקון תבנית):
```
cd nir-reports && git pull
cd field-report-bot && docker compose up -d --build
```
החיבור לוואטסאפ נשמר (לא צריך לסרוק QR שוב) כי הוא נשמר ב-Docker volume נפרד.

### פקודות שימושיות

- `docker compose logs -f` — צפייה בלוג חי (למשל אם דוח לא נוצר כמצופה)
- `docker compose restart` — הפעלה מחדש
- `docker compose down` — עצירה מלאה (החיבור לוואטסאפ עדיין נשמר)

## חשוב לדעת

- הבוט מזהה נתונים (לקוח, כתובת, ממצאים) מתוך הטקסט באמצעות AI — כדאי
  לכתוב הערות בצורה ברורה (למשל: "לקוח: בית ספר ביאליק", "כתובת: הרצל 5").
  אפשר תמיד לפתוח את קובץ ה-Word שהתקבל ולתקן ידנית אם משהו זוהה לא נכון.
- אם התוכן שנשלח לא מכיל מספיק פרטים, שדות ריקים בדוח יישארו ריקים —
  הבוט לא ממציא נתונים.
- כדי לעדכן את התבניות עצמן (טקסטים קבועים, שוליים, לוגו) בעתיד — הם
  מוגדרים ב-`src/docGenerator.js`, זהה למבנה שב-`nir-reports/src/lib/docGenerator.js`.
