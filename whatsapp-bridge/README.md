# WhatsApp Bridge — גשר וואטסאפ לניר הנדסה

שירות קטן שרץ במחשב (או שרת) ומקשיב לצ'אט וואטסאפ אחד. כל מה שנשלח
לצ'אט הזה — טקסט ותמונות — נשמר זמנית, ואפליקציית "ניר הנדסה" (nir-reports)
שואבת אותו בלחיצת כפתור אחת במסך "🤖 כתיבת דוח AI" ("ייבוא מוואטסאפ"),
במקום להעתיק־להדביק ידנית.

זה לא משתמש ב-WhatsApp Business API הרשמי (שדורש אישור עסקי ותשלום) — הוא
מתחבר לחשבון וואטסאפ רגיל בדיוק כמו WhatsApp Web, דרך סריקת קוד QR.

## התקנה חד־פעמית

1. התקן [Node.js](https://nodejs.org) (גרסה 18 ומעלה).
2. בתיקייה `whatsapp-bridge`, הרץ:
   ```
   npm install
   cp .env.example .env
   ```
3. ערוך את `.env`:
   - `WHATSAPP_TARGET_CHAT` — שם מדויק של הצ'אט שהשירות יקשיב לו (מומלץ:
     צור קבוצת וואטסאפ ייעודית בשם למשל "דוחות שטח", עם עצמך כחבר יחיד).
     רק הודעות מהצ'אט הזה נקראות — כל השאר מתעלם.
   - `RESET_KEYWORD` — מילה ששולחים לצ'אט כדי לפתוח קליטה חדשה ולנקות את
     מה שנאסף קודם (ברירת מחדל: "דוח חדש").
4. הרץ:
   ```
   npm start
   ```
5. ייפתח קוד QR בטרמינל. סרוק אותו מהטלפון: WhatsApp ← הגדרות ←
   מכשירים מקושרים ← קישור מכשיר. אחרי הסריקה הראשונה השירות זוכר את
   ההתחברות ולא צריך לסרוק שוב (אלא אם מתנתקים ידנית).

## שימוש יומיומי בשטח

1. בקבוצה/בצ'אט הייעודי בוואטסאפ, שלח בזמן הביקור: טקסט חופשי (הערות,
   כתובת, ממצאים) ותמונות — כמה שרוצים, לפי הסדר.
2. כשסיימת, פתח את אפליקציית "ניר הנדסה" → "🤖 כתיבת דוח AI" → לחץ
   "📲 ייבוא מוואטסאפ" — הטקסט והתמונות מהצ'אט ייטענו אוטומטית לתיבה.
3. המשך כרגיל: "צור דוח עם AI" ← בדוק/ערוך ← "ייצא ל-Word".
4. כדי להתחיל אוסף חדש (ביקור הבא), שלח בצ'אט את מילת האיפוס (למשל
   "דוח חדש"), או פשוט — ה"ייבוא מוואטסאפ" מנקה את התור אחרי שהוא נטען.

## הרצה קבועה ברקע

השירות צריך לרוץ ברציפות כדי לקלוט הודעות. הפשוט ביותר: השאר את
הטרמינל עם `npm start` פתוח על מחשב שדולק תמיד, או הגדר אותו כשירות עם
[pm2](https://pm2.keymetrics.io/) (`pm2 start index.js --name whatsapp-bridge`)
או במשימה מתוזמנת/Task Scheduler שמריצה אותו בהתחלת ההפעלה — באותו אופן
שבו `nir-dashboard-new/autostart` מריץ את הדשבורד אוטומטית.

## API מקומי (לשימוש הפנימי של האפליקציה)

- `GET /status` — מצב חיבור וכמות פריטים ממתינים.
- `GET /qr` — קוד QR (base64 image) כשעדיין לא מחובר.
- `GET /inbox` — הטקסט המצטבר (משורות) והתמונות הממתינות.
- `POST /inbox/clear` — ניקוי התור אחרי ייבוא.

כברירת מחדל השירות מאזין על `http://localhost:3210` — ניתן לשנות עם
`PORT` בקובץ `.env` (יש לעדכן בהתאם גם בהגדרות "ייבוא מוואטסאפ" באפליקציה).
